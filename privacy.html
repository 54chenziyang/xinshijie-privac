一、我们如何收集和使用您的个人信息

心世界是一款单机养成类游戏，单机与局域网联机玩法无需注册或登录账号即可游玩；在 TapTap 渠道包中，您可以选择使用 TapTap 账号登录以启用云存档、多人联机等可选功能；若您主动使用「联网游戏」（公共世界），则需要注册一个公共世界账号，该账号由我们自建的服务器承载（见第五部分之二）。我们不收集您的手机号码、姓名、身份证件号码、通讯录、精确位置、麦克风等可识别您个人身份的信息，亦不进行实名认证。

（一）我们如何收集您的个人信息

  1. 游戏存档。 您在游戏内的昵称、角色外观、金币、农田、心灵之森及游戏进度等数据，默认仅保存在您本机的应用存储中（浏览器本地存储 localStorage），不会上传。只有在以下两种情形才会离开本机：① 您主动使用 TapTap 云存档时，进度经 TapSDK 上传并存储于 TapTap 云端；② 您主动使用「联网游戏」时，账号、公共大陆与农场进度会上传并保存在我们自建的服务器（118.178.112.216）（Android 客户端经 HTTPS，网页版 / 桌面版经 HTTP 入口），详见第五部分之二。
  2. 可选的联机服务。 心世界支持由玩家自行发起的局域网 / 点对点联机（用于互相参观农场、在同一房间内活动）。当您主动开启联机并加入房间时，为实现联机功能，您与其他参与玩家的设备之间会直接传输以下游戏内数据：您在游戏内的昵称、角色外观、位置坐标、农场快照等。上述数据不包含您的手机号、身份证号等身份信息，且仅在参与联机的设备之间实时传输，局域网 / 点对点联机不设集中式服务器；「联网游戏」的公共世界则使用我们自建的服务器（见第五部分之二）。为发现同一局域网内的房间，应用可能读取本地网络信息（如局域网广播 / 组播），该过程不会将您的个人信息上传给我们。
  3. 扫描二维码加入房间。 您可以通过扫描二维码加入联机房间，此时需要调用设备相机。相机仅用于识别二维码，我们不会保存、上传或用于其他用途。
  4. 设备信息与设备标识符。 为实现 TapTap 渠道包内的 TapTap 账号登录、云存档、多人联机与版本更新唤起等功能，我们接入了 TapSDK（详见第五部分）。在您点击“同意”本政策之后，TapSDK 会在本机读取设备信息与设备标识符，包括 AndroidID、广告标识符（GAID）、匿名设备标识符（OAID）、设备型号、系统版本、CPU、网络类型、内存等，用于生成设备标识、设备识别与账号安全校验，并经加密通道随网络请求传输至 TapTap 服务器。其中 AndroidID 与其他标识符仅在 GAID / OAID 无法获取时作为回退方案读取。我们未开展广告业务，上述信息不会被用于广告推送或与游戏无关的用途。
  5. 公共世界账号、进度与互动数据（仅「联网游戏」与好友功能）。 当您主动注册 / 登录公共世界时，我们会收集账号名、密码（服务端加盐哈希保存，不保存明文）、公共大陆与农场的建造与进度、好友关系与私聊内容、偷菜与举报记录，以及服务器记录的 IP 地址与设备型号 / 系统版本，用于登录鉴权、进度保存、好友与互动功能、安全风控。上述数据由 Android 客户端经 HTTPS（TLS 1.2 及以上）加密传输、网页版 / 桌面版经 HTTP 入口传输，保存在我们自建的服务器（118.178.112.216），不向任何第三方共享。
